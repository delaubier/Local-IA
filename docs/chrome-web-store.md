# Présentation Chrome Web Store

## Nom

LocalAI

## Description courte

Votre assistant IA local : discutez, dictez et analysez vos pages, images et documents directement dans le navigateur.

La description courte du manifeste est fournie en français et en anglais, dans `public/_locales`, avec l’anglais comme langue de repli. Les icônes PNG 16, 32, 48 et 128 px reprennent le symbole de l’application.

## Description détaillée proposée

LocalAI place un assistant IA dans le panneau latéral de votre navigateur. Rédigez, posez vos questions, analysez des documents ou dictez votre message, tout en restant sur votre page.

La génération des réponses et la reconnaissance vocale s’exécutent sur votre appareil. Les modèles sont téléchargés à votre demande, puis conservés localement pour être réutilisés. Aucune clé API de service de génération n’est nécessaire.

- Chat avec le modèle LFM3, ou avec un fichier GGUF compatible que vous importez.
- Dictée multilingue avec Whisper Tiny, Base ou Small, avec détection de la langue parlée.
- Résumé de pages, analyse d’images et de captures, lecture de documents et de PDF.
- Recherche web automatique pour compléter les connaissances du modèle, avec des liens vers les sources citées.
- Conversations enregistrées sur cet appareil, recherche, épinglage et export.
- Thèmes clair et sombre, interface française ou anglaise, réglages propres à chaque modèle.
- Commandes pour supprimer un modèle, tous les modèles ou toutes les conversations.

Les modèles nécessitent de l’espace de stockage, de la mémoire et un navigateur compatible. Les performances dépendent de l’appareil. Une connexion est nécessaire pour télécharger les modèles et utiliser la recherche web. Les requêtes de recherche sont envoyées aux moteurs consultés ; les pages et modèles sont récupérés auprès de leurs hébergeurs. Les réponses de l’IA peuvent contenir des erreurs.

Ce texte et les icônes sont préparés pour la fiche. Aucune publication n’est effectuée par ce projet.
